# 清华医学物理 2027 备考操作系统

手机打开后可添加到主屏幕。数据存在这台手机的浏览器里，不上传。

## 怎么用

1. 用电脑把整个文件夹放到任意静态网站，或本机打开：
   `python3 -m http.server 8765`
2. 手机和电脑同一网络时，浏览器访问 `http://电脑IP:8765`
3. Safari / Chrome 选“添加到主屏幕”

## 已经接上的系统

- 首页战情地图、今日任务、忙/出差/饭局模式
- 353 四科 + 英语 + 政治的学习与闭卷
- 练习、错题、间隔复习、计时模拟考

题库是按大纲写的原创练习，不是学长真题。真题以后有合法来源再挂进去。
