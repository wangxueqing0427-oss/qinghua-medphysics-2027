# 清华医学物理 2027 备考系统 · V32 英语总审计版

本版不继续盲目堆英语材料，先按“基础较弱、只用手机，能否一路学到真题阶段”的标准做总审计并修复关键逻辑。

## 审计结论
- 英语基础训练系统可以阶段性封板：12章课程、1012个第一层训练词、63篇原创短阅读、40句长难句、16篇中长阅读/64题、6篇完形/24空、6组新题型、20句翻译、10个写作输出题均已形成手机训练入口。
- 不能宣称英语最终完成：真实历年英语一真题尚未导入；第二层识别词与个人弱词应由后续真实真题和训练数据继续补充。
- 原创训练材料继续明确不冒充真题。

## V32关键修复
- 修复词汇闸门：以前“见过一次”会抬高覆盖率；现在把“见过”和“真正掌握”分开。真正掌握要求至少两次间隔回忆正确。
- 第一层词汇放行条件改为：至少见过950/1000、至少850/1000达到两次间隔回忆正确、当前弱词率≤20%。这是内部训练标准，不是官方要求。
- 修复每日10词选词：到期弱词 → 未见新词 → 到期熟词 → 其他弱词；不再随机抽已熟词浪费最低任务。
- 写作“有效草稿”改用英文词数：小作文训练稿≥80词，大作文训练稿≥140词，避免用字符数误判。
- 新增 `#/english/audit` 英语总审计页，直接显示内容量、已满足项、真实外部依赖和个人词汇状态。
- PWA缓存版本升级，减少手机继续加载旧JS的概率。

## V41 学习连续性 + 周计划发动机

## V42 学习时间与完成度自适应

- 正常/忙碌/出差/饭局后仍是第一层时间约束，自适应只在其基础上缩放，不强行加压。
- 未完成任务不按分钟机械累加到第二天，避免“计划债务”越滚越大。
- 新增任务量自适应页面，展示近期完成度、当前档位与调节原因。
