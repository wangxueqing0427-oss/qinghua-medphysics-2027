01 放射与核技术：先建立总地图
  • 核心链条：射线产生/来源 → 与物质相互作用 → 能量沉积 → 剂量测量 → 临床治疗或成像。
  • 重点射线：X 射线、γ 射线、电子束；后续扩展到质子、碳离子束。
  • 必须会区分：X 射线通常由电子减速或电子能级跃迁产生；γ 射线来自原子核能级变化。两者本质都是电磁辐射，但来源不同。
  • 考试思路：给一种射线/设备，说明来源、主要相互作用、剂量特点和临床用途。
02 放射治疗物理学基本概念
  • 吸收剂量 D：单位质量物质吸收的平均能量，单位 Gy；这是放疗剂量学最核心的量之一。
  • 剂量率：单位时间内的剂量，临床上会影响照射效率及部分生物学效应。
  • 射野：治疗束流在患者或模体中的空间范围；理解中心轴、深度剂量和横向剂量分布。
  • 核心关系：能量、距离、介质、几何条件共同影响剂量分布；放疗物理最终目标是让靶区得到处方剂量，同时尽量保护正常组织。
03 剂量测量与探测器
  • 为什么测量：确认机器输出、建立剂量基准、校准治疗计划、进行 QA。
  • 常见思路：电离室通过电离产生的电荷测量剂量；半导体探测器体积小、响应快；胶片可提供二维剂量分布信息。
  • 必须会比较：准确性、空间分辨率、能量依赖、剂量率依赖、测量体积和临床适用场景。
  • 易错：“探测器读数”不是天然等于“吸收剂量”，必须经过校准和相应修正。
04 X/γ 射线射野剂量学
  • 第一重点：深度剂量分布——理解表面剂量、剂量随深度变化、最大剂量深度等概念。
  • 第二重点：横向剂量分布——理解射野边缘、半影、均匀性和对称性。
  • 第三重点：影响因素包括能量、射野大小、SSD/SAD、组织密度和几何条件。
  • 考试答题：先画/描述剂量随深度变化，再说明能量或几何条件变化造成的趋势。
05 高能电子束剂量学
  • 特点：电子在组织中的射程有限，适合表浅或较浅部位治疗。
  • 关键概念：射程、表面剂量、剂量峰值及远端快速下降。
  • 与光子束比较：光子可产生较深部剂量；电子束在达到一定深度后剂量下降明显。
  • 临床理解：选择电子束还是光子束，本质是根据靶区深度和正常组织保护需求选择剂量分布。
06 近距离放疗剂量学
  • 基本原理：把放射源放到肿瘤内部或附近，使靶区获得高剂量并利用距离效应快速降低周围剂量。
  • 高频概念：放射源、源强、距离、剂量率、源的几何位置和衰变。
  • 与外照射比较：外照射源在体外；近距离放疗源靠近或进入治疗区域。
  • 考试重点：为什么距离变化会显著影响剂量；如何通过源的位置和停留时间控制剂量分布。
07 IMRT 调强适形放疗
  • 目的：让高剂量区更贴合靶区，同时降低重要危及器官受量。
  • “调强”：不是简单改变总剂量，而是改变不同射束/子野的强度分布。
  • 计划过程：靶区与危及器官勾画 → 设定处方和约束 → 优化 → 生成可执行计划 → QA。
  • 易错：IMRT 的“强度调制”与 IGRT 的“图像引导”不是一回事。
08 IGRT 图像引导放疗
  • 目的：利用治疗前/治疗中影像确认患者和靶区位置，减少摆位误差及器官运动带来的影响。
  • 基本链条：定位 → 获取影像 → 与参考影像配准 → 判断偏差 → 必要时修正位置 → 治疗。
  • 与 IMRT：IMRT解决“剂量怎么优化”；IGRT解决“人/靶区在哪里”。两者经常联合使用。
09 模拟定位与治疗计划系统 TPS
  • 模拟定位：在治疗前确定患者体位、靶区位置和治疗几何条件，为后续计划与复现提供基础。
  • TPS：输入影像、靶区、危及器官和机器/束流参数，计算并优化治疗计划。
  • 计划设计核心：处方剂量、靶区覆盖、剂量均匀性、危及器官限量、机器可实施性。
  • 易错：“TPS算得漂亮”不等于“临床一定安全”，还需要独立检查、计划验证和 QA。
10 质子与碳离子治疗
  • 质子：带电粒子，在组织中具有明显的能量沉积峰特征，可利用其深度剂量分布减少部分正常组织受量。
  • 碳离子：重带电粒子，具有高线性能量传递等特点，同时涉及更复杂的生物学效应。
  • 核心比较：光子/电子 vs 质子/碳离子：既比较物理剂量分布，也要考虑设备、射程不确定性和生物学效应。
  • 考试表达：不要写成“质子一定比光子好”，应写“在特定临床场景下可利用其物理剂量优势减少正常组织受量，但需综合评估适应证、射程和资源等因素”。
11 放疗 QA：为什么机器每天都要检查
  • 目的：保证治疗设备、剂量输出、几何精度和计划实施与要求一致。
  • 层级：日常/周期性设备检查、剂量校准、几何参数检查、计划验证和患者特异性 QA。
  • 核心思想：“计划正确”+“机器正确”+“执行正确”才等于安全治疗。
  • 高频题：给出某项 QA 异常，要求判断可能影响、风险和处理流程。
12 辐射防护
  • 基本原则：正当性、优化（ALARA）和剂量限值等构成辐射防护的重要框架。
  • 三大操作原则：时间尽量短、距离尽量远、屏蔽合理。
  • 对象：工作人员、患者、公众的防护目标和具体要求不同。
  • 易错：患者接受治疗所需照射属于医学照射，不能简单套用职业照射的剂量限值逻辑。
13 核医学成像仪器：先搞懂三台机器
γ相机
探测放射性核素发出的γ射线，形成平面或动态影像。
SPECT
在γ相机基础上进行旋转采集和重建，得到断层分布信息。
PET
利用正电子湮没产生的成对511 keV光子进行符合探测和断层成像。
共同点
都是核医学成像，核心链条是“示踪剂 → 放射性信号 → 探测 → 重建 → 图像解释”。
  • 高频比较：γ相机/SPECT与PET的放射性来源、探测方式、空间信息和临床用途。
  • 不要死背：先把“信号从哪里来、机器怎么收到、最后怎么形成图像”讲通。

📖 01｜X射线、γ射线、电子、质子、碳离子——一张图记住（详细背诵版）
逐条背：
  1. X射线与γ射线本质都是光子，区别首先看来源：X射线主要来自电子运动/能级变化或电子减速；γ射线主要来自原子核能级变化。
  2. 制动辐射：高速电子在原子核库仑场中减速或改变运动状态时产生连续能谱X射线，是医用直线加速器产生高能X射线的重要机制。
  3. 特征X射线：内层电子空位被外层电子填补时产生特定能量光子。
  4. 电子、质子、碳离子都带电，进入组织后可直接产生电离和激发并沉积能量；质子和碳离子还可利用有限射程和射程末端剂量峰。
  5. 考试一句话：光子重“穿透和散射”，电子重“有限射程”，质子/碳离子重“射程末端剂量集中”。
  6. 不要把“X射线”和“γ射线”理解成两种完全不同的物质；它们都是电磁辐射。
闭卷要求：至少能不看手机，用自己的话连续讲出本章的核心链条、2个高频比较点和1个易错点。
📖 02｜吸收剂量、剂量率、Gy、Sv——剂量学第一关（详细背诵版）
逐条背：
  1. 吸收剂量D=单位质量物质吸收的平均能量，单位Gy，1 Gy=1 J/kg。
  2. 剂量率=单位时间接受的剂量；总剂量和剂量率不是一个概念。
  3. 放疗处方剂量是治疗计划规定的目标剂量，不等于机器某个瞬间的读数。
  4. Gy用于吸收剂量；Sv用于辐射防护中的当量剂量/有效剂量概念。考试中看到Gy和Sv要立刻区分。
  5. 放疗不是“剂量越大越好”，核心是肿瘤控制与正常组织保护之间的平衡。
  6. 影响剂量分布的因素包括能量、深度、射野、距离、组织密度、入射方向和患者几何条件。
闭卷要求：至少能不看手机，用自己的话连续讲出本章的核心链条、2个高频比较点和1个易错点。
📖 03｜电离室、半导体、胶片——为什么要测剂量（详细背诵版）
逐条背：
  1. 电离室通过辐射在气体中产生的电离电荷来测量辐射量，具有稳定、准确、可追溯等特点，是临床参考剂量学的重要工具。
  2. 半导体探测器体积小、响应快、空间分辨率高，适合部分小野和高梯度区域，但要考虑能量响应等因素。
  3. 胶片能记录二维剂量分布，空间分辨率高，适合剂量分布验证。
  4. 探测器原始读数不能直接等同于患者吸收剂量，必须经过校准和必要修正。
  5. 选择探测器要同时考虑准确性、空间分辨率、能量依赖、剂量率依赖、体积效应和使用场景。
  6. QA依赖剂量测量：没有可靠测量，就无法知道机器输出和计划实施是否正常。
闭卷要求：至少能不看手机，用自己的话连续讲出本章的核心链条、2个高频比较点和1个易错点。
📖 04｜X/γ射野剂量学——深度剂量和横向剂量（详细背诵版）
逐条背：
  1. 深度剂量描述中心轴上剂量随深度变化，是理解光子束治疗的基础。
  2. 高能光子束通常有剂量建立区，并在dmax附近达到最大剂量；之后随深度增加逐渐下降。
  3. 射线能量升高通常使dmax更深、深部穿透能力增强，但实际结果还受散射和几何条件影响。
  4. 横向剂量分布描述同一深度从射野中心到边缘的剂量变化。
  5. 半影是射野边缘剂量快速变化的区域；可从几何、机械、散射等角度理解。
  6. 均匀性看射野内部剂量是否平坦；对称性看中心轴两侧对应位置是否一致。
  7. 考试遇到“为什么剂量变化”，优先判断是能量、深度、射野大小还是SSD/SAD改变。
闭卷要求：至少能不看手机，用自己的话连续讲出本章的核心链条、2个高频比较点和1个易错点。
📖 05｜高能电子束——为什么适合浅表病变（详细背诵版）
逐条背：
  1. 电子束带电且具有有限射程，适合表浅或较浅部位治疗。
  2. 电子进入组织后不断损失能量，超过一定深度后剂量快速下降，因此深部出口剂量较低。
  3. 重点记：表面剂量、射程、剂量峰值、远端快速下降。
  4. 电子束不是“没有深部剂量”，而是“达到一定深度后快速下降”。
  5. 电子束和质子都带电，但质量、相互作用和临床剂量学特点不同，不能混为一谈。
  6. 选择电子还是光子，本质上是在选择适合靶区深度和形状的剂量分布。

📖 06｜近距离放疗——源的位置就是剂量的一部分（详细背诵版）
逐条背：
  1. 近距离放疗把放射源放入肿瘤内部或附近，使靶区获得高剂量并利用距离效应降低较远处组织剂量。
  2. 剂量与源强、距离、照射时间/停留时间、源的几何位置和衰变有关。
  3. 外照射源在患者体外；近距离治疗源靠近或进入治疗区域。
  4. 距离变化可显著改变局部剂量，因此源位置误差可能造成明显剂量误差。
  5. 后装治疗通过计算机控制放射源在导管内的位置和停留时间，形成计划剂量分布。
  6. 答题可用“源近→局部高剂量→距离增加剂量快速下降→保护远处正常组织”的链条。

📖 07｜IMRT——调的是强度，不是简单加大剂量（详细背诵版）
逐条背：
  1. IMRT通过调节不同射束/子野的强度分布，让高剂量区更贴合靶区，同时降低危及器官受量。
  2. 典型流程：影像→靶区/危及器官勾画→处方和约束→逆向优化→计划生成→验证/QA→治疗。
  3. “调强”指空间强度分布的调制，不是简单提高总剂量。
  4. 逆向计划的思想：先提出希望达到的剂量目标，再由优化算法寻找可实施的束流参数。
  5. IMRT最容易和IGRT混淆：IMRT解决剂量如何分布；IGRT解决患者/靶区在哪里。
  6. IMRT越复杂，越需要可靠的计划验证和机器QA。
闭卷要求：至少能不看手机，用自己的话连续讲出本章的核心链条、2个高频比较点和1个易错点。
📖 08｜IGRT——把“人在哪里”纳入治疗（详细背诵版）
逐条背：
  1. IGRT利用治疗前或治疗中的影像确认患者、靶区或器官位置，减少摆位误差和运动影响。
  2. 基本链条：摆位→影像→配准→判断偏差→必要时校正→治疗。
  3. 当剂量梯度很陡时，小的几何误差可能造成靶区欠量或危及器官超量，因此高精度治疗尤其重视IGRT。
  4. IGRT不是“拍片就结束”，关键是影像信息参与治疗位置决策。
  5. 与IMRT比较：IMRT=剂量塑形；IGRT=位置校正。两者经常联合。

📖 09｜模拟定位与TPS——从影像到可执行计划（详细背诵版）
逐条背：
  1. 模拟定位的任务是确定患者体位、靶区位置和治疗几何条件，为计划和每日复现提供基础。
  2. TPS输入患者影像、靶区、危及器官、机器和束流参数，计算并优化治疗计划。
  3. 计划评价至少包括靶区覆盖、剂量分布、危及器官限制和机器可实施性。
  4. 典型计划流程：明确处方→勾画→选束流/能量/方向→优化→评价→确认可实施→验证。
  5. TPS是计算和优化工具，不是治疗机器本身。
  6. “TPS算得漂亮”不等于“临床一定安全”，还需要独立检查、计划验证和QA。

📖 10｜质子/碳离子——布拉格峰与射程不确定性（详细背诵版）
逐条背：
  1. 质子和碳离子是带电粒子束，可利用其深度剂量特征把较高能量沉积集中在射程末端附近。
  2. 布拉格峰：带电粒子在射程末端附近能量沉积明显增加的特征。
  3. 相较光子，特定情况下可减少部分正常组织的出口剂量。
  4. 质子治疗的重要挑战之一是射程不确定性：组织密度、解剖变化和计划误差都会影响实际射程。
  5. 碳离子除物理剂量外，还涉及高LET和相对生物效应等因素，因此物理与生物学都要考虑。
  6. 考试不要写“质子/碳离子一定更好”，应写“在特定适应证和几何条件下可能具有优势”。

📖 11｜QA——计划正确、机器正确、执行正确（详细背诵版）
逐条背：
  1. QA目标：保证设备输出、剂量、几何精度、计划计算和实施过程符合规定要求。
  2. QA可包括日常检查、周期性检查、剂量校准、几何参数检查、计划验证和患者特异性QA。
  3. 安全链：计划正确 + 机器正确 + 摆位正确 + 执行正确。
  4. 复杂调强治疗涉及大量叶片运动、子野和剂量调制，因此更需要可靠QA。
  5. 发现QA异常不能只看“有没有超阈值”，还要判断临床影响、复核原因并按流程处理。
  6. 计划验证主要针对某个计划能否按要求实施；设备QA更多关注机器本身的稳定性和性能。

📖 12｜辐射防护——正当性、优化、剂量限值（详细背诵版）
逐条背：
  1. 辐射防护的重要框架：正当性、优化（ALARA）和剂量限值。
  2. 正当性：辐射照射必须有合理收益。
  3. 优化：在达到目的前提下，使不必要的照射尽可能低。
  4. 时间尽量短、距离尽量远、屏蔽合理，是常用的操作防护原则。
  5. 工作人员、公众、患者的防护逻辑不同；患者医学照射不能简单套用职业照射剂量限值。
  6. 屏蔽设计要结合辐射种类、能量、工作负荷、距离和建筑布局等因素。

📖 13｜γ相机、SPECT、PET——三台机器一条链（详细背诵版）
逐条背：
  1. γ相机：探测放射性核素发出的γ射线，可进行平面或动态成像。
  2. SPECT：在γ相机基础上进行多角度旋转采集和断层重建，得到三维放射性分布。
  3. PET：正电子核素发射正电子；正电子与电子湮没后产生两个约511 keV光子，利用符合探测和重建获得图像。
  4. PET探测的关键不是直接“看见正电子”，而是探测湮没产生的511 keV光子。
  5. γ相机常用准直器限制入射方向；准直会提高空间定位能力但牺牲部分探测效率。
  6. 三者共同链条：示踪剂→放射性信号→探测→定位/重建→图像解释。
  7. 高频比较：SPECT偏单光子断层；PET偏符合探测和正电子湮没产生的511 keV双光子。
闭卷要求：至少能不看手机，用自己的话连续讲出本章的核心链条、2个高频比较点和1个易错点。
