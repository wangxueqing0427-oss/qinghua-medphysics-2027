按 2026 官方考试范围整理｜先掌握“定义—框架—高频考点—答题句式”
学习顺序建议
①公共卫生基础②健康指标③三级预防④卫生体系/政策/经济⑤应急⑥全球健康⑦健康教育
答题原则：先给定义，再列分类/框架，最后结合场景解释。不要只背名词。
第1章 公共卫生基础：是什么、做什么
  • 公共卫生：以人群为对象，通过有组织的社会行动预防疾病、促进健康、延长寿命并改善生活质量。
  • 核心对象：从“治疗个体”扩展到“保护人群”；强调群体风险、环境因素、社会决定因素和预防。
  • 核心功能：监测健康状况；发现和调查健康问题；告知/教育/动员；制定政策；执法；提供/保障服务；评价服务效果等。
  • 公共卫生与临床：临床主要面对个体诊断治疗；公共卫生主要面对人群预防与健康促进，两者互补。
  • 考试句式：“公共卫生强调以人群健康为核心，通过监测、预防、健康促进和政策行动降低健康风险。”
第2章 健康指标与健康评价
  • 死亡指标：粗死亡率、年龄别死亡率、死因别死亡率、病死率。
  • 出生/生育：出生率、总和生育率等，用于描述人口再生产。
  • 患病与发病：发病率强调“新发生病例”；患病率强调“某一时点/期间现有病例”。
  • 寿命：平均预期寿命是综合评价人群健康水平的重要指标。
  • 综合健康指标：把死亡与生存质量、失能等结合，用于比较不同人群健康水平。
  • 易错：发病率常用于描述疾病发生风险/病因研究；患病率受发病和病程长短共同影响。
第3章 疾病预防与控制：一级、二级、三级
  • 一级预防：疾病发生前，针对危险因素和健康决定因素，防止疾病发生。例：疫苗接种、控烟、健康生活方式。
  • 二级预防：疾病早期，通过早发现、早诊断、早治疗阻止或延缓进展。核心：筛查/早诊。
  • 三级预防：疾病已经发生后，减少残疾、并发症和死亡，促进康复。
  • 经典陷阱：筛查属于二级预防；但筛查对象通常是无症状人群，必须结合筛查试验性能和后续确诊流程。
  • 疾病控制：降低疾病发生、传播或危害；“消除/消灭”比“控制”目标更高，范围和实现条件不同。
第4章 卫生系统、卫生政策与卫生经济
  • 卫生系统：围绕改善人群健康而组织的机构、人员、资源、制度、筹资和服务体系。
  • 关键组成：卫生服务提供、人力资源、卫生信息、药品/技术、卫生筹资、治理等。
  • 卫生政策：政府及相关主体为解决卫生问题、配置卫生资源和改善健康而采取的制度与行动。
  • 卫生经济学：研究卫生资源有限条件下如何配置资源，以提高效率、公平和健康产出。
  • 常考权衡：效率≠公平；低成本≠低价值；政策评价要同时关注效果、成本、可及性和公平。
  • 我国卫生保障：理解医疗保障、卫生服务供给、筹资与支付之间的基本关系，不必死背复杂政策条文。
第5章 健康中国与卫生政策分析
  • 健康中国：把人民健康放在优先发展的战略位置，强调预防为主、全生命周期健康管理和共建共享。
  • 政策分析框架：问题界定 → 目标 → 备选方案 → 利益相关者/可行性 → 成本与效果 → 实施 → 监测评价。
  • 答题：遇到“如何解决某公共卫生问题”，优先写“人群—危险因素—干预—资源—实施—评价”六步。
  • 健康公平：关注不同地区、收入、年龄、职业等人群获得健康机会和卫生服务的差异。
第6章 突发公共卫生事件与应急管理
  • 应急链条：风险评估/预防 → 监测预警 → 应急响应 → 处置与救援 → 恢复重建 → 复盘改进。
  • 核心能力：快速监测、信息报告、流行病学调查、实验室检测、风险沟通、资源调配和多部门协同。
  • 风险沟通：及时、准确、透明，解释风险大小、不确定性和公众可采取的行动。
  • 易错：应急管理不是“出了事再处理”，而是全过程管理，预防和准备同样重要。
第7章 全球健康、国际卫生与健康促进
  • 全球健康：关注跨国界、跨地区影响健康的问题，以及需要国际合作解决的健康挑战。
  • 国际卫生条例（IHR）：重点理解其公共卫生事件监测、通报和国际协作意义。
  • 健康促进：使人们增强控制和改善自身健康的能力；不仅是“告诉知识”，还要改变环境、政策和社会支持条件。
  • 健康教育：通过有计划的信息传播和教育活动促进健康行为；健康促进的范围更广。
第8章 高频综合题：拿分模板
  • “设计防控方案”：①明确人群与问题 → ②描述疾病负担 → ③找危险因素 → ④一级/二级/三级预防 → ⑤资源与组织 → ⑥监测评价。
  • “评价一项政策”：目标是否明确 → 覆盖/可及性 → 健康效果 → 成本/效率 → 公平 → 实施可行性 → 副作用。
  • “突发事件处置”：预警 → 核实 → 报告 → 调查 → 控制传染源/切断传播途径/保护易感人群 → 风险沟通 → 评价。
  • “健康教育方案”：需求评估 → 确定目标人群 → 行为与环境分析 → 干预 → 实施 → 效果评价。
